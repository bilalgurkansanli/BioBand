## Synthesized additions

Generated by `scripts/make_extra_drum_samples.py` (pure-stdlib Python, deterministic; encode with ffmpeg libmp3lame `-q:a 2`, mono 44.1 kHz):

- `sidestick.mp3` — side-stick / rim click (noise click + damped 1.7 kHz / 810 Hz / 335 Hz modes). Played when the snare's outer rim zone is hit.
- `808/*.mp3` — full 808-style kit (kick, snare, rim, 3 toms, hats, crash, ride) used by the **electronic** drum kit via `KIT_SOUND_OVERRIDES`: gliding-sine drums with tanh drive, stacked-square metallic hats/cymbals.

## Processing

Re-encoded with ffmpeg (`libmp3lame` VBR `-q:a 2`), mono 44.1 kHz:

- Soft highpass / lowpass as needed
- **Crash:** short musical hit (~1.1 s), strong upper-mid / air cuts, fade-out — not a 3–4 s tinny wash
- Mild compression on kick only
- Peak normalize / limiter (~−1 dB) — avoid aggressive `loudnorm I=-16`
