# Raw captures

Drop unedited phone screenshots here — straight off the device, no cropping,
no resizing, and not sent through anything that recompresses them.

`scripts/store_screenshots.py` reads this folder and writes store-ready
variants; it needs the original pixels to find the status bar and to hit the
stores' exact dimensions without scaling twice.

The finished images do not belong here. Nothing in this folder is used by the
app or the README.
